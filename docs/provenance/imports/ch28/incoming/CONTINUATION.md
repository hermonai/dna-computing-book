# Continuity contract
DNAD-27 defined a symbolic CRN as species counts plus stoichiometric transitions.
DNAD-28 adds quantitative time semantics without changing that reaction graph:
deterministic mass-action ODEs model continuous concentrations; Gillespie's direct
SSA models integer molecule counts and random event times. The chapter requires
units, volume/copy-number conversion, conservation checks, ensemble statistics and
an explicit statement that one stochastic trajectory is not an expectation curve.
