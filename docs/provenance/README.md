# Provenance and review evidence

`imports/` preserves earlier Chapter 22–32 package inventories and integration
notes. Its paths resolve relative to `archive/legacy/dna-computing-book/`.
Incoming declarations are not local validation; old hashes do not certify
the relocated sources.

`archive/manifest.json` binds the pre-reorganization tracked tree and locally
present review PDFs to archived copies. The canonical chapter manifest records
their new locations. `build/book/build-record.json` binds each new PDF to its
current sources.

The durable reorganization review records regression results, rendered-page
scope and open release gates. Reorganization is not scientific acceptance.
