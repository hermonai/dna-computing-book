# Internal pedagogical review

These are review perspectives applied by the same authoring assistant, not independent specialists or external peer review.

| Perspective | Strong objection | Revision / remaining gate |
| --- | --- | --- |
| Molecular biologist | Strings hide polarity, chemistry and concentration. | Teach nucleotide structure and oriented strands before complement code; obtain biological figure review. |
| DNA-computing researcher | A history ending at Adleman misrepresents the field. | Add CRNs, circuits, assembly, storage interfaces and a dated frontier section. |
| Theoretical computer scientist | Parallel test tubes can conceal exponential resources. | Count molecular copies, operations, error and readout; state model variants before complexity claims. |
| Software engineer | Simulations can look like laboratory predictors. | Every package function states its abstraction and omitted physics. |
| Graduate beginner | Three methodology chapters postpone the subject. | Start with a concrete example and embed evidence practice in worked cases. |

Decision: the new learning order is suitable for a first chapter research pass. It is not locked for publication. Open gates: formal-model bibliography, physical mechanism figures, full classical experiment reconstruction and external subject review.
