# Contributing

Contributions are welcome when they preserve the book's evidence boundaries.

Before opening a pull request:

1. add or update the relevant claim-ledger entry;
2. cite primary sources for priority, mechanism, or quantitative scientific claims;
3. keep molecular execution, simulation, differentiable modeling, and AI architecture distinct;
4. add tests for executable semantics;
5. state model width, state dimension, parameter budget, data, seeds, and artifacts for comparative claims;
6. preserve negative results and corrections;
7. run `python3 -m pytest`.

Do not commit source PDFs without confirmed redistribution rights. This public repository currently carries no general reuse license; contributions do not change that status.
