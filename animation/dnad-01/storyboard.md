# Chapter 1 static keyframes

Nine-stage DNA process or seven-stage computational process, as applicable. These are original SVG keyframes, not a rendered animation or a laboratory protocol. Each frame changes the highlighted conceptual stage and its concrete state panel. Later adaptation in Evolutor is a question, not implemented behavior.

- Frame 1: Graph — V = {A,B,C,D,E,F}; start A; finish F.|Nine edges constrain consecutive vertices..
- Frame 2: Codes — Each O_v = L_v R_v; domain lengths both h.|Codes name vertex identity, not validated sequences..
- Frame 3: Edges — A→B supplies a_R b_L; B→C supplies b_R c_L.|An antiparallel B splint aligns the nick..
- Frame 4: Mix — Edge fragments + complementary splints + suitable reagents.|Amounts and physical conditions are intentionally unspecified..
- Frame 5: Candidates — 106 legal walks of 1..7 vertices in the executable model.|ABCBDF repeats B; ABDEF omits C..
- Frame 6: Endpoints — 14 model candidates begin at A and finish at F.|ABCDEF, ABCBDF and ABDEF still survive..
- Frame 7: Length — 4 candidates contain six vertex occurrences.|ABDEF is removed; ABCBDF is still retained..
- Frame 8: Coverage — 2 candidates contain all six required identities.|ABCBDF is removed because E is absent..
- Frame 9: Verify — ABCDEF and ACBDEF both pass the independent verifier.|An injected ABECDF would fail adjacency here..
